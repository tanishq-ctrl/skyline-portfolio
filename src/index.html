800 spreadsheets in, one database out

At Beta Realty the lead data sat in 800 spreadsheets, each laid out differently, and finding one record could take days. This replays the pipeline I built, slowed down so you can watch it work.

Time to find a record
days
  1. Extract. Read every workbook and every sheet in it.
  2. Map columns. Detect each file’s layout and map it onto one schema.
  3. Clean. Fix types and formats so values can be compared.
  4. Remove duplicates. Apply the agreed matching rules.
  5. Load. Write the validated records to one database, with lead priority attached.

The share of duplicates in the replay is illustrative. Replace the file count and record total with your own.
